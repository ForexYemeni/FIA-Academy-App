# تطبيق أكاديمية المستقبل الدولية 📱

تطبيق أندرويد رسمي لـ [أكاديمية المستقبل الدولية](https://fiaacademy.vercel.app) — FUTURE INTERNATIONAL ACADEMY

غلاف WebView احترافي بمحرك إشعارات فورية أصلي — دون أي تعديل على كود الموقع.

## ⬇️ تحميل التطبيق

**[تحميل أحدث إصدار (APK) من هنا — Releases](https://github.com/ForexYemeni/FIA-Academy-App/releases/latest/download/FIA-Academy.apk)**

## المميزات (حتى الإصدار v2.4)

- 🔔 **إشعارات فورية أصلية** — خدمة خلفية تفحص الإشعارات كل 5 ثوانٍ والشاشة مضاءة (30 ثانية مطفأة) حتى والتطبيق مغلق، مع إزالة تكرار ذكية
- 🔐 جلسة دخول محفوظة بعد إغلاق التطبيق (Cookies + localStorage)
- 🛡️ شاشة تقرير العطل — عند أي انهيار مستقبلي تظهر رسالة قابلة للتصوير مع زر «متابعة إلى التطبيق» بدل الإغلاق الصامت
- 📷 رفع الصور من الكاميرا والمعرض (مستندات الطلاب والمعلمين)
- 🔗 الروابط الخارجية (واتساب/هاتف/بريد) تفتح في تطبيقاتها
- ⬅️ زر الرجوع يتنقل داخل الموقع ولا يخرج إلا من الرئيسية
- 🎨 هوية الأكاديمية: كحلي `#334264` + ذهبي `#D8A346` + أيقونة من الشعار الرسمي
- 📴 شاشة «لا يوجد اتصال» عربية أنيقة مع زر إعادة المحاولة
